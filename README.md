# Amythyst Games

Static game files served through [jsDelivr](https://www.jsdelivr.com/) for the Amythyst browser's games pane.

## Layout

- `n-gon.html` — n-gon (single-file game)
- `icons/` — game icons

## Serving via jsDelivr

```
https://cdn.jsdelivr.net/gh/<owner>/<repo>@<tag-or-branch>/<file>
```

## Notes

- Files are hosted raw and must keep correct MIME types on delivery.
- Only add games you have the right to distribute.
